TWITCH BACKUP RECORDER · MAC & WINDOWS

Your recorder, on each computer.

Share this page with another computer. Install once there, then choose its streamers. Each computer records and saves its own files independently.

Mac

  1. Install Homebrew if you do not already have it.
  2. Open Terminal, paste this command, and press Return. It installs the recorder and opens its control panel.
curl -fsSL https://raw.githubusercontent.com/ewanders1-web/twitch-auto-recorder/main/backup/Install.command -o /tmp/twitch-backup-install.command && bash /tmp/twitch-backup-install.command

Next time: Finder → Go → Go to Folder, paste ~/Library/Application Support/TwitchBackupRecorder, then open Start Backup.command.

Requires a Mac supported by current Homebrew and Python 3.11. The first install may take several minutes.

Windows 10 / 11 (64-bit Intel or AMD)

  1. Open Windows PowerShell, paste this command, and press Enter.
  2. Accept any Python or FFmpeg installer prompts. The recorder opens when setup finishes.
Invoke-WebRequest -UseBasicParsing 'https://raw.githubusercontent.com/ewanders1-web/twitch-auto-recorder/main/backup/Install.ps1' -OutFile "$env:TEMP\twitch-backup-install.ps1"; if ($?) { powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$env:TEMP\twitch-backup-install.ps1" }

Next time: press Win+R, paste %LOCALAPPDATA%\TwitchBackupRecorder, then open Start Backup.cmd.

Automatic dependency setup uses winget (Microsoft App Installer). If unavailable, setup explains how to install Python 3.11 and FFmpeg manually.

Start recording

  1. On each computer, open its launcher and leave that window open.
  2. In the control panel, add a Twitch channel and click Start watching.
  3. Open Recordings for originals and numbered music parts.
  4. Click Stop watching before closing the launcher. Let processing finish before shutting down.
Open this computer’s recorder

Keep the computer powered and awake. Originals stay on that computer. Vocal removal runs one job at a time and music is split into roughly 30-minute parts. The first job downloads its separation model. Recording starts only after you click Start watching; this does not install an automatic startup service.

Run the install command again to update, after stopping watchers and letting processing finish. Recordings and settings are kept. Each computer needs its own installation; this page does not control other computers or upload recordings to Drive.
