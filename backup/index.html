How it works

1. Run Install.command once to set up the recording tools.
2. Add your streamers and click Start watching.
3. Keep the launcher window open while recording.
4. Open Recordings to download the music parts.

This backup uses its own local service on port 8766. It can run beside your original recorder. Vocal removal uses Demucs and may leave some vocal remnants. Processing can take a while; it continues while new recordings begin. Closing this browser tab keeps the recorder running. Closing the launcher stops watching. No Drive upload is enabled.
