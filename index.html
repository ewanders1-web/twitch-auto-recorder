demucs not installed — pip install demucs (first run downloads models), then restart the helper.
Auto Music only (Recorder Settings toggle) builds -music / -vocals siblings during/after capture on finished segments. This tab's upload remains for arbitrary files. History rows still have Music only / Redo for disk files.
Calls Twitch Helix API from your browser. UI: open from GitHub Pages on any computer, or http://127.0.0.1:8765/ / file://. Recording: still needs the Python helper on the machine that saves files (streamlink → ~/TwitchRecordings). Pages cannot record by itself.

1Any machine setup

1. Open the UI: https://ewanders1-web.github.io/twitch-auto-recorder/

2. On the machine that should save recordings, install the helper:
curl -fsSL https://raw.githubusercontent.com/ewanders1-web/twitch-auto-recorder/main/install.sh | bash
(Windows: see install.ps1 in the repo.)

3. pip install streamlink (optional: demucs, ffmpeg for Music only / seamless).

4. Start the helper (install script prints the command, or python3 twitch-recorder-server.py from the install dir). It stays on 127.0.0.1:8765 only — Pages → localhost is OK via CORS when the helper runs on that same machine.

2Create a Twitch app

Go to dev.twitch.tv/console → Register Your Application.
OAuth Redirect URL: https://localhost · Category: Other. Copy Client ID and generate a Client Secret.

3Enter credentials

⚠️ Saved in this browser's localStorage — never transmitted except to Twitch's OAuth endpoint.

4Poll interval

Twitch recommends ≥ 30 s to avoid rate limits.

5Optional local helper (manual)

Prefer the Any machine setup install script above. Manual: copy files next to each other, pip install streamlink, then python3 twitch-recorder-server.py and open http://127.0.0.1:8765/. Records to ~/TwitchRecordings. Helper binds localhost only. You can still use this HTML as a file:// tab-capture app without the helper.

6Helper auto-update (GitHub)

Public repo ewanders1-web/twitch-auto-recorder. Check compares local helper VERSION / HELPER_VERSION to remote, then can download HTML + server + README into the install dir (Application Support when installed).
